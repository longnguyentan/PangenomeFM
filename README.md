# PangenomeFM

Research software for learning representations of pangenome sequence variation.

The current **v3 research prototype** and its documentation are on the
[`codex/pangenomefm-v3-20261011` branch](https://github.com/longnguyentan/PangenomeFM/tree/codex/pangenomefm-v3-20261011/v3).
This link is suitable for the project QR code while development continues.

The prototype includes sequence-aware multiallelic outputs, positional axial
attention, query-isolated population attention, paired frozen-random controls,
and TRAIN-only internal selection/metric protocols. It is under active
experimental evaluation. **Validated imputation improvements, external
replication and biological gains have not yet been established.** No trained
weights or cohort data are released here.

The existing `src/` tree on `main` is the historical implementation. See the
v3 branch for the current portable prototype and its input schema; neither code
availability nor successful software checks establishes scientific performance.
