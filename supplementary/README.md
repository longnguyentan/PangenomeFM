# Supplementary material workspace

- `figures/`: exposure, calibration, full chromosome/seed/fold, ablation, runtime and robustness figures.
- `tables/`: canonical fold/seed results, graph inventories, comparator conversion, complexity definitions and downstream matrices.
- `text/`: extended methods, evidence limitations, data exclusions and reproducibility details.

Only script-generated or explicitly source-cited artifacts should be promoted into the manuscript.
